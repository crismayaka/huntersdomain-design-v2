Design set v2 · for review · 2026-11-07

Twelve pages, one design system

V2 of the site, published so the team can read it in a real browser instead of from disk. Every page shares one token file and one block stylesheet. Prices, counts and timestamps show the inventory feed's shape, not live figures.

These are review copies. Routes inside them point at the file that stands in for the route, so a click stays in this folder. Anything the design has not decided yet is marked as a gap — F2 fee, F4 CPW dates, F6 verification date. They are not production routes and nothing here is wired to the inventory feed.
